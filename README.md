# Jomtien Ride

A browser-playable version of Jomtien Ride. The game is a self-contained HTML file with artwork and audio embedded, so it can be played locally without installing anything.

## Play

Open `Jomtien-Ride.html` in Firefox, Chrome, or another modern desktop browser. Click **Start** to begin.

- **Right Arrow** or **D**: hold to accelerate
- **Space** or **Left Arrow**: hold to brake
- **Up / Down Arrow**: change lanes
- The on-screen controls also work with a mouse or touch screen

The debug console below the controls reports page startup, loading errors, and input events.
